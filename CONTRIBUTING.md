# Contributing to Awesome Agent OS

Thanks for helping. This list stays short on purpose, so every pick has to earn its place.

## A pick gets in when

1. It is open source with a clear license.
2. It does **one job** in a personal AI operating system, and does it better or simpler than what is already listed.
3. It is alive: a release or real commits in the last six months.
4. You have used it, or you can say in one sentence why it matters.

## How to suggest one

Open an issue with the template **New pick**, or a pull request that adds one line in the right section:

```markdown
- **[name](https://github.com/owner/name)** · One sentence on the job it does.
```

Star counts are filled in by script, leave them out. No affiliate links, no closed-source tools, no self-promotion without disclosure.

## Removing a pick

If a project is dead, archived or changed its license, open an issue with the link. Removals are as welcome as additions.
